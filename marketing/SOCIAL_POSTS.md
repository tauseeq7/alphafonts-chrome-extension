### Day 3: Tip post (educational, low promotion)
**X thread**
1. > 3 ways to find the font a website uses (and when to use each) 🧵
2. > 1) DevTools: Right-click, Inspect, Computed tab, font-family. Works everywhere, but slow.
3. > 2) A font inspector extension: hover over text and read it. Best for quick checks and for studying many fonts. (Mine: https://alphafonts.com/font-inspector-extension/)
4. > 3) Identify from an image: use a font-identification site when the text is in a picture or logo, because extensions only read real text.
5. > Bonus: the font name in CSS is only what the site asks for. A fallback font may be what you actually see.

**LinkedIn**
> 3 ways to find the font on any website:
>
> 1️⃣ DevTools (Inspect, Computed, font-family): works everywhere, but slow.
> 2️⃣ A font inspector extension: hover and read. Best for quick checks.
> 3️⃣ An image-based font identifier: for text that is inside a picture or logo.
>
> One caveat: the CSS shows the fonts a site *asks for*. If a font fails to load, the browser shows a fallback.
>
> Which method do you use? 
> (My extension for #2, free: https://alphafonts.com/font-inspector-extension/)
