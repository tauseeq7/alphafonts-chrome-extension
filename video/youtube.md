## Description
Want to know what font a website is using? AlphaFonts Font Inspector shows you the font, size, weight, line height, letter spacing and color of any text, and lets you copy the CSS in one click.

In this 1-minute demo:

WHAT YOU GET
- Font family, size, weight, style, line height, letter and word spacing, alignment, transform, decoration and color (HEX or RGB)
- Copy CSS, a plain-text summary or the element's selector
- "Label all text on page": a small label above every text element
- Live editing with sliders and px / rem / em / unitless converters
- Contrast checker with a suggested passing color
- Copy only the changes you made, with undo for each value
- Light and dark themes, keyboard shortcut (Alt+Shift+F) and right-click menu

PRIVATE AND FREE
It runs on your computer. No account, no tracking, nothing is collected or sent anywhere.
