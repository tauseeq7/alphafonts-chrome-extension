Page labels

The popup's Label all text on page button puts a small label above every text element. Choose what the labels show. Settings that are just the browser default (normal style, no spacing, left aligned) are left out to keep labels short. Abbreviations: lh line height, ls letter spacing, ws word spacing.

Live editing

Lock an element, then press Edit values in the panel to try a new size, weight, color and more directly on the page. Use ↑ / ↓ in number fields (hold Shift for bigger steps). Edits are temporary: Reset edits, Remove layers in the popup, or a page reload undo them.
